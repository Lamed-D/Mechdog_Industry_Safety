# 사용자가 보존한 장치 시작 파일 백업

사용자가 제공하고 공개 보존을 승인한 boot.py와 main.py의 원본 바이트를 텍스트 확장자로 보관합니다.
실제 장치에서 에이전트가 다시 읽어 대조한 백업은 아니며 사용자가 저장한 파일의 사본입니다.
SHA-256과 크기는 manifest.json에서 확인합니다. 펌웨어 전체·보정값·동작 파일까지 백업했다는 뜻은 아닙니다.

**실행·import·자동 업로드하지 마세요.** main 백업에는 로봇 생성·이동·자세·동작 코드가 포함돼 있습니다.
이는 복구 보존용이며 현재 프로젝트의 안전성 검토를 통과한 펌웨어가 아닙니다.
문서 범위 밖 인자·동작과 통신 정지 감시 미구현 경로가 있으므로 예제로 재사용하지 않습니다.
현재 사용자 허용 범위는 비전 확인뿐입니다. 장치 시작 파일 변경과 복구 실행은 별도로 승인된 범위에서만 합니다.
복구가 필요하면 사용자가 파일 내용·대상 보드·기존 버전을 확인한 후 확장자를 원래대로 돌리는 절차를 별도로 검토합니다.
이 파일을 테스트·프로그램 탐색 경로에 포함하지 않습니다.
