# 하드웨어 구성·배선·전원

제품 제시값과 실측값을 구분합니다. 표기: **[확인]** 회로도·데이터시트·예제로 확인 / **[확인 필요]** 실물로 확인해야 함.
근거는 제조사 회로도(V1.2)·기술 사양서·제조사 예제, 공개 데이터시트입니다(저장소 미포함).
제어 API 규칙은 [mechdog-api.md](mechdog-api.md), 펌웨어는 [firmware.md](firmware.md), 라이다 설계·중계 상세는 [lidar-frozen.md](lidar-frozen.md).

## 1. 현재 구성

| 구성 | 내용 |
| --- | --- |
| 로봇 | Hiwonder MechDog **1대**: 다리 4개(서보 8개), 팔·집게·꼬리·부가 서보 장치 없음 |
| 앞쪽 | 비전 모듈(ESP32-S3), 맞춤 Arduino 영상 펌웨어 |
| 등 위 | RPLIDAR A1M8-R6, 테이프 고정. **동결**: 대시보드 표시 시연용만, 추가 개발 없음. 지도 작성은 추후 VSLAM |
| 호스트 | Windows 노트북 1대, PC 화면 `python -m dashboard.server` → [dashboard.md](dashboard.md) |

- **확장(미래):** 같은 구성의 로봇 A/B 두 세트. A/B는 고정 ID로만 씁니다.
- 본체 MicroPython(메인 ESP32)과 카메라 펌웨어(ESP32-S3)를 혼동하지 않습니다.
- 라이다는 테이프 고정이므로 사용 전 고정 상태와 정면(0°) 방향을 확인합니다.
- 장치를 새로 달면 이 문서와 [mechdog-api.md](mechdog-api.md) 0절·7.3절을 같은 PR에서 고칩니다.

## 2. 본체·전원 (제품 제시값)

| 항목 | 값 | 남은 확인 |
| --- | --- | --- |
| 서 있는 크기 | 214×126×138 mm | 라이다·카메라·배선 포함 외형 |
| 무게 | 약 560 g (+ 라이다 약 170 g) | 최종 장착 무게 |
| 다리 | 8자유도, 고속 서보 8개 + 링크 | 하중 추가 후 자세·직진·회전 |
| 배터리 | 7.4 V, 1500 mAh, 5C | 라벨·상태·실효 운용 시간 |
| 운용 시간 표기 | 최대 60분 | 영상·무선·라이다·보행 포함 조건 **미측정**. 보증값 아님 |
| 보드 입력 | 6~8.4 V | — |
| 메인 칩 | **ESP32(클래식)** [확인], 순정 MicroPython v1.21.0 (ESP-IDF v5.0.2) | 보드 회로도 버전(V1.0/V1.2) [확인 필요] |
| 충전기 | 8.4 V 2 A | 동봉품 라벨·커넥터 |

- 메인 칩은 ESP32-S3가 **아닙니다**. 회로도의 메인 모듈은 ESP32-DevKitC 배치이고, ESP32-S3는 비전 모듈의 칩입니다(홍보 이미지 표기는 혼동).
- 공식 근거: [제품 페이지](https://www.hiwonder.com/products/mechdog), [준비·충전 안내](https://docs.hiwonder.com/projects/MechDog/en/latest/docs/1.Getting_Ready.html).
- 충전은 전원을 끄고 동봉 충전기로, 완료 표시 후 분리. **에이전트는 배터리 연결·충전·전원 조작을 하지 않습니다.**
- 배터리 전압은 `Hiwonder.Battery_power()`(mV)로 읽고, 낮으면 노트북에 알리고 시연을 멈춥니다. 저전압 임계값은 미정·실측 필요.

실제 장착 라벨이 다르면 이 값을 적용하지 않습니다. 부품 명세일 뿐 Python 인자·허용 자세 범위가 아닙니다.

| --- | --- | --- | --- | --- | --- |
| 6~8.4 V | 6 kgf·cm @8.4 V | ≤0.06 s/60° @8.4 V | 32×12×26 mm, 14.5 g | ≤25 mA / ≤2.5 A | 500~2500 µs / 0~180° |

근거: [공식 서보 사양](https://www.hiwonder.com/products/hps-0618sg). 다리를 직접 PWM으로 구동하지 않고, 스톨 시험도 하지 않습니다.

## 3. 메인 ESP32 핀 배정 [확인: 회로도 + 제조사 라이브러리]

| 기능 | 핀 |
| --- | --- |
| 서보 1~10 | IO25, 26, 27, 14, 16, 17, 15, 2, 0, 4 |
| 서보 11(회로도에만) | IO12 |
| I2C 1 (SDA1/SCL1) | IO22 / IO23 |
| I2C 2 (SDA2/SCL2) | IO19 / IO13 |
| 부저 / LED / 버튼 | IO21 / IO18 / IO5 |
| 배터리 전압 / IMU 인터럽트 | IO34 / IO35 |
| USB 시리얼(REPL, UART0) | IO1 / IO3 |
| **GPIO 포트 J5** | **IO32 / IO33** — 다른 기능과 겹치지 않음 |

- I2C 코드 번호(`IIC(1)`/`IIC(2)`)와 물리 커넥터 대응은 장치별 확인 필요. 최신 얼굴 예제는 물리 포트 1 → 코드 `IIC(2)`.
- 비전 모듈(ESP32-S3) 쪽 I2C 슬레이브 핀: SDA 47 / SCL 48.
- 제조사 라이브러리는 터치 센서(IO33)·조도 센서(`analogRead(33)`)를 J5 핀으로 읽습니다 → **J5에 라이다를 쓰므로 터치·조도 센서를 함께 쓰지 않습니다.**
- UART: UART0=REPL, UART2 기본 핀(IO16/IO17)은 서보 5·6 → 라이다는 **UART1을 IO32(RX)/IO33(TX)에 지정**.

### 3.1 남는 GPIO

| 핀·전원 | 사용 가능 여부 |
| --- | --- |
| IO32, IO33 (J5-4, J5-3) | **유일한 빈 범용 GPIO.** 라이다 UART로 쓰면 남는 GPIO 없음 |
| IO0, IO4 (서보 9·10) | 불가. 부가 서보가 없어도 순정 드라이버가 10채널 모두 PWM 출력. IO0은 부팅 핀 |
| IO12 (서보 11) | 불가. 부팅 시 플래시 전압 결정 핀 |
| IO36, IO39 | 불가. 커넥터에 없음 |
| I2C 포트 2개 | I2C 장치 전용 |
| J5-1 5 V | 신호·소형 센서용. 라이다 전원으로는 실측 전 사용 금지 |

→ 센서를 더 달려면 I2C 방식을 고릅니다(공식 버스 공유는 사용자에게 먼저 확인, [mechdog-api.md](mechdog-api.md) 7.2절).

## 4. J5 핀 배치 [확인: 회로도 V1.2]

| J5 핀 | 신호 | 라이다 연결 |
| --- | --- | --- |
| 1 | 5 V | **연결 안 함**(5 V 레일 여유 미확인) |
| 2 | GND | 라이다 GND + 별도 전원 GND 공통 |
| 3 | IO33 = MechDog **TX** | 라이다 RX |
| 4 | IO32 = MechDog **RX** | 라이다 TX |

- TX/RX 방향은 제조사 시리얼 강좌(어댑터 TXD·RXD·GND → IO32·IO33·GND, 교차)와 제조사 Arduino 예제(`HardwareSerial(1)`, rx 32, tx 33)로 확인. 첫 실물 연결 응답으로 재확인.
- 실물 커넥터 1번 핀 위치, J5 커넥터 형번 **[확인 필요]**.
- 제조사 시리얼 예제(9600bps `CMD` 메시지)는 같은 J5를 쓰므로 업로드하지 않습니다.

## 5. RPLIDAR A1M8 배선 [공개 데이터시트 rev 3.0]

라이다 본체 커넥터는 두 개입니다. 개발 키트 케이블이 3핀+4핀을 어댑터 보드 쪽 7핀으로 모읍니다.

| 커넥터 | 규격 | 핀(도면 왼→오) |
| --- | --- | --- |
| 모터 | PH1.25 3핀 | 5V_MOTO, CTRL_MOTO, GND_MOTO |
| 측정 코어 | PH1.25 4핀 | GND, VCC_5V, RX, TX |

도면 왼→오가 실물 1번→끝과 같은지, 케이블 선 색 **[확인 필요]**. 화면 좌우만 보고 꽂지 않습니다.

| 라이다 신호 | MechDog 쪽 | 전압 | 비고 |
| --- | --- | --- | --- |
| TX (출력) | J5-4 IO32 | 3.3 V TTL, High 2.9~3.5 V | 보호용 220~330 Ω 직렬 저항 허용 |
| RX (입력) | J5-3 IO33 | 3.3 V TTL, High 1.6~3.5 V | **직렬 저항 금지**(전류로 신호 인식, 1.6 V 밑으로 떨어지면 안 됨) |
| GND | J5-2 + 별도 전원 GND | 0 V | 공통 접지, 한 점 |
| VCC_5V | 별도 5 V | 4.9~**5.5 V 최대**, 리플 ≤50 mV | **9 V 금지** |
| 5V_MOTO | 별도 5 V (1단계는 VCC_5V와 같은 전원) | 5~9 V | 초기엔 5 V만, 고속 회전 시도 안 함 |
| CTRL_MOTO | **VCC_5V(5 V)에 연결 → 모터 항상 켬** | 0~약 5 V | 5V_MOTO에 묶지 않음(모터 전원을 올리면 한계 초과). J5에 남는 GPIO가 없어 모터 제어 불가 |
| GND_MOTO | 별도 전원 GND | 0 V | J5-2와 공통 |

- UART 115200bps 8N1 **고정**(921600bps 같은 고속은 다른 라이다에서만 의미).
- 레벨 변환기 불필요: 라이다 TX 최대 3.5 V < ESP32 입력 한계 3.6 V, ESP32 TX 3.3 V는 라이다 RX 범위 안.
- 측정 거리 0.15~12 m(흰색 대상 조건). 데이터시트 측정 성능과 UART 전송량(5바이트 표준 패킷)은 구분합니다.
- UART 설정: `machine.UART(1, baudrate=115200, rx=32, tx=33, rxbuf=4096)`. 순정 `machine.UART`는 `baudrate/tx/rx/txbuf/rxbuf/timeout/timeout_char` 인자 문자열 확인, 실제 동작은 J5 루프백 확인 필요.

## 6. 라이다 전원

| 항목 | 값 [데이터시트] |
| --- | --- |
| 코어 | 4.9~5.5 V, 리플 20 mV(최대 50 mV), 기동 500 mA(최대 600 mA), 동작 300 mA(최대 350 mA), 대기 80 mA |
| 모터 | 5~9 V, 5 V에서 약 100 mA |
| 합계 | 동작 약 0.4~0.45 A, 기동 순간 최대 약 0.7 A → **5 V 1 A 이상** 전원 |
| 권장 | 코어·모터 전원 분리, 코어 리플 1% 미만 |

단계:

0. **라이다 단독:** 키트 USB 어댑터로 노트북에 직결(전원·모터·데이터 모두 USB). 데이터용 micro-USB 케이블 필요(키트 미포함).
1. **1단계(시험):** USB 보조배터리(5 V 2 A 이상) 또는 실험용 전원(5 V, 전류 제한 1 A)으로 별도 구동. MechDog와는 **GND·UART 두 선만** 연결.
2. **전류 실측:** 기동·정상 회전 전류를 데이터시트(합계 0.4~0.7 A)와 비교해 기록.
3. **2단계(탑재, 실측 후 결정):** 권장 = **P11(VIN) → 소형 DC-DC 강압(5 V, 1 A 이상) → 라이다 코어·모터**. 로직 5 V 레일에 부담 없음.
   MP1584 같은 모듈도 입력 범위·출력·기동 전류·리플·발열을 사용자 실측 후 사용. 배터리 VIN 직접 공급은 기본 구성으로 쓰지 않습니다.
   J5-1 사용은 비전 모듈과 같은 레일이므로 여유가 확인될 때만.
4. **노이즈 대책:** 라이다 전원 입력에 100~470 µF 전해 + 100 nF 세라믹, 배선 짧게, GND 한 점 공통.

필요 부품(2단계 기준): PH1.25 3핀·4핀 피그테일(키트 케이블은 자르지 않음), J5용 4핀 케이블(형번 확인 필요), DC-DC 강압 모듈, P11용 3PIN 케이블, 콘덴서, 220~330 Ω 저항, 방진 패드. 구매는 사용자만 합니다.

## 7. 비전 모듈 (ESP32-S3)

- 칩 ESP32-S3. 센서 실제 모델·플래시 용량·PSRAM은 **[확인 필요]**. 컴파일 설정(DIO 80 MHz·4 MB·OPI PSRAM)은 실제 용량을 증명하지 않습니다.
- 제품 표의 영상 320×240은 제시된 동작값이며 센서 최대 해상도가 아닙니다. 맞춤 펌웨어 해상도 프로필은 실제 JPEG 크기·성능으로 확인 → [firmware.md](firmware.md).
- 메인 보드와는 I2C(4.4절 [mechdog-api.md](mechdog-api.md)), 영상은 Wi-Fi HTTP(80/스트림 81)로 노트북에 → [protocol.md](protocol.md).
- 전원 5 V 2 A 이상.
