# 제조사 인터페이스와 우리 통신의 구분

아래 주소는 제조사 예제·공식 문서·순정 문자열에서 확인한 사실 또는 확인 필요 항목입니다.
주소가 있다는 이유로 장치가 장착됐거나 해당 버스에 응답한다고 보지 않습니다.
공식 장치 제어는 Hiwonder_IIC를 통해서만 합니다.

## I2C 장치 표

| 장치 | 주소 | 코드 인터페이스·상태 |
| --- | --- | --- |
| MPU6050 | 0x68 | 제조사 라이브러리 근거. 공식 MPU(IIC(1)) 읽기 사용, 실제 칩 확인 필요 |
| QMI8658 | [확인 필요] | 순정 문자열에 이름만 확인. 주소·실물 판별 전 raw 접근 금지 |
| 초음파 | 0x77 | 제조사 라이브러리 근거, I2CSonar 사용. 현재 장착 여부 별도 확인 |
| 카메라 구형 레지스터 방식 | 0x53 | 맞춤 펌웨어 기본 주소, 실제 Python 세대별 응답 확인 필요 |
| 카메라 명령 방식 | 0x52 | 제조사 카메라 예제 근거. 0x53과 동시에 응답하지 않음 |
| 음성 | 0x79 | 제조사 라이브러리 근거, 장착·버스 미확인 |
| MP3 | 0x7B | 제조사 라이브러리 근거, 장착·버스 미확인 |
| 별도 IoT Wi-Fi 모듈 | 0x69 | 공식 IoT 강좌 근거. 우리 통신은 메인 ESP32 내장 Wi-Fi이며 이 모듈을 전제하지 않음 |

IoT 근거: [공식 IoT 강좌](https://wiki.hiwonder.com/projects/MechDog/en/latest/docs/9.IOT_Expanded_Lesson.html).
물리 포트 번호와 코드 IIC 번호는 같다고 가정하지 않습니다. 최신 얼굴 예제는 **물리 IIC 포트1 → 코드 IIC(2)**입니다.
다른 강좌에는 카메라 IIC(1)도 있으므로 전체 포트를 숫자만으로 일괄 대응하지 않습니다.
회로 신호는 SDA1/SCL1=IO22/23, SDA2/SCL2=IO19/13으로 기록돼 있으나 Python의 코드 번호와
실물 커넥터 대응은 장치별 확인이 필요합니다. 카메라 쪽 슬레이브 핀은 SDA47/SCL48입니다.

## 제조사 시리얼·앱 기능 코드

제조사 시리얼 예제는 J5에서 9600bps 8N1로 CMD 구분자 메시지를 사용합니다.
우리 라이다 UART의 115200bps와 동시에 포트를 열 수 없습니다. 이 예제 프로그램은 업로드하지 않습니다.

| 기능 코드 | 의미 | 확인할 단위·범위 |
| --- | --- | --- |
| 1 | 자세·자기 균형 | 하위 기능별 인자, 좌표 축은 문서 세대 차이 확인 |
| 2 | 기본·사용자 동작 그룹 | 번호와 실제 동작 이름 대응 확인 |
| 3 | 방향별 이동 | 방향 코드와 우리 move(step,angle)는 다른 인터페이스 |
| 4 | 초음파 읽기·회피 기능 | 시리얼 반환은 mm. Python getDistance 반환 단위는 실물 확인 필요 |
| 5 | IMU 기울기 읽기 | x/y 각도(도) |
| 6 | 배터리 읽기 | mV |

근거: [공식 시리얼 강좌](https://docs.hiwonder.com/projects/MechDog/en/latest/docs/5.Arduino_Programming_Projects.html).
제조사 앱·군집 메시지를 우리 UDP 제어로 그대로 전달하지 않습니다.
제조사 Wi-Fi 예제는 STA_IF와 UDP 9027을 쓰는 것을 확인했습니다. 모든 앱 세대의 공통 포트라고 단정하지 않습니다.
우리 포트는 CMD 9100 / TEL·ROLE ACK 9101 / 라이다 TCP 20108 / 카메라 HTTP80·스트림81입니다.

## 동작 편집·보정

공식 PC 편집기는 동작별 시간과 서보 값을 목록으로 편집하며, 좌표 모드는 다리의 x/z 위치를 조절합니다.
이 좌표는 ROS 지도 좌표·우리 move의 보폭/회전 인자가 아닙니다. 보정은 제조사 출하 상태가 기준이며
PC 도구는 읽은 편차를 장치에 저장하는 기능을 제공합니다.
[공식 동작 편집 안내](https://docs.hiwonder.com/projects/MechDog/en/latest/docs/7.Action_Editing_Course.html).

동작 그룹 파일의 정확한 바이너리/텍스트 형식, 버전 호환성, 보정 저장 매체·내구성은 **[확인 필요]**입니다.
편집기 연결 자체가 자세를 바꿀 수 있으므로 사용자 실물 작업으로만 진행합니다.
문자열에서 발견한 보정·서보 후보 API는 [규칙](dev/mechdog-api.md)에 따라 존재만 점검하고 호출하지 않습니다.
