# 비공개 자료 규칙

이 프로젝트는 외부 저장소와 제조사 자료를 **참고만** 합니다. 참고한 내용은 기밀이므로 저장소 기록에 남기지 않습니다.

## 1. 남기지 않는 것

커밋(파일·메시지), PR 제목·본문, 이슈, 리뷰 코멘트, 문서 어디에도 다음을 쓰지 않습니다.

- 참고한 외부 저장소의 이름, 주소, 소유자, 로컬 경로
- 참고 자료 폴더·파일의 이름과 경로
- 참고 자료의 코드·문구를 그대로 옮긴 것 (내용을 이해한 뒤 우리 방식으로 새로 작성합니다)
- 개인정보(이름, 연락처, 주소)와 비밀 정보(Wi-Fi 비밀번호, 토큰)

근거가 필요하면 "제조사 회로도", "제조사 예제", "공개 데이터시트"처럼 **일반적인 이름**으로만 적고,
공개된 공식 문서는 공개 URL로만 인용합니다.

## 2. 참고 자료를 두는 곳

- 참고 자료는 저장소 **밖**에 두거나, 저장소 안이라면 `.private/`, `refs/`, `references/` 처럼 `.gitignore`가 막는 폴더에 둡니다.
- 특정 참고 자료 이름을 무시 목록에 넣을 때는 공개되는 `.gitignore`가 아니라 **`.git/info/exclude`** 에 적습니다.

## 3. 자동 검사

- `tools/check_confidential.py`가 커밋·커밋 메시지·푸시에서 비공개 낱말을 찾으면 막습니다.
- 낱말 목록은 저장소에 올리지 않는 **`.confidential-terms`** 파일(작업 폴더 맨 위)에 있습니다. 목록 자체도 비밀이므로
  문서·코드·커밋에 그 내용을 옮겨 적지 않습니다.
- 훅 설치(작업 폴더마다 한 번):

  ```bash
  git config core.hooksPath tools/hooks
  ```

- 훅을 끄거나 우회(`--no-verify`)하지 않습니다. 검사가 막으면 내용을 고칩니다.
- 푸시 전에 직접 확인할 때:

  ```bash
  python tools/check_confidential.py range origin/main..HEAD
  ```
