# 로봇 공식 API 대조표

제조사 Python 예제 전체와 순정 MicroPython v1.21.0 이미지의 읽을 수 있는 문자열을 대조했습니다.
역컴파일하지 않았습니다. 문자열 존재는 인자·반환값·실행 시간의 보증이 아닙니다.
기준 표는 [공식 API 규칙](dev/mechdog-api.md)입니다. 실물 REPL 결과가 우선합니다.

사용자 지정 우선순위는 **본체에 실제 설치된 Python 구현·실물 반환 결과 → 제조사 Python 예제 → 공식 문서 보조 설명**입니다.
PC에서는 본체 구현 원본 Python 소스를 아직 찾지 못해 직접 구현 대조는 미완료입니다. 아래 예제/문자열 근거를 실제 구현을 읽은 것으로 간주하지 않습니다.
통합 main 적용 전 [본체 동작 체크리스트](user-tests/robot-python-checklist.md)의 읽기·루프·동작 시험을 A/B 각각 수행해야 합니다.

| 호출 / 인자 | 제조사 예제 | 순정 문자열 | 규칙 표 | 사용 범위 |
| --- | --- | --- | --- | --- |
| `MechDog()` | 있음 | 있음 | 있음 | 시작 초기화 |
| `move(step, angle)`, `move(0,0)` | 있음 | 있음 | 있음 | motion, 시작 정지; 프로젝트 제한 ±100/±30 유지 |
| `action_run(name)` | 있음 | 있음 | 있음 | 허용 목록만; 아래 이름 주의 |
| `stop_action()`, `action_is_over()` | 있음 | 있음 | 있음 | 래치 정지·완료 확인 |
| `set_default_pose()` | 있음 | 있음 | 있음 | 동작 후 기본 자세 |
| `set_gait_params(100,300,20)` / `(150,500,40)` | 있음 | 있음 | 있음 | 가짜 범위 검사; 런타임 미사용 |
| `transform(xyz,rpy,ms)`, `set_pose(xyz,abc,ms)` | 있음 | 있음 | 있음 | 가짜 검사; 런타임 미사용 |
| `homeostasis(bool)`, `read_homeostasis_status()` | 있음 | 있음 | 있음 | 가짜 검사; 런타임 미사용 |
| `Hiwonder.startMain(func)` | 있음 | 있음 | 있음 | 전역 조립 뒤 루프 등록, 매회 sleep_ms 양보 |
| `Hiwonder.Battery_power()` | 있음 | 있음 | 이번 대조로 보강 | 배터리 mV, 실패는 NA |
| `Buzzer()`, `playTone(freq,ms,bool)` | 있음 | 있음 | 있음 | 가짜 검사 |
| `Button(1/2)`, `Clicked(callback)` | 있음 | 있음 | 있음 | 가짜 검사 |
| `IIC(1)`, `MPU(iic)`, `read_angle()` | 있음 | 있음 | 이번 대조로 보강 | IMU 실패는 NA, 칩·방향 실물 확인 |
| `IIC(2)`, `ESP32S3Cam(iic)`, `read_face()` | 있음 | 있음 | 있음 | 얼굴 읽기 우선; 낙상 판단에 쓰지 않음 |
| `face_recognition()` | 있음 | **찾지 못함** | 있음 | 구형 장치에서만 호환 읽기; 없으면 unknown |
| `I2CSonar(iic)`, `getDistance()`, `setRGB(n,r,g,b)` | 있음 | 있음 | 있음 | 가짜 검사; 런타임 미사용 |
| `set_servo(...)` | 있음 | 있음 | **사용 금지** | 가짜는 항상 예외, 실제 부가 장치 없음 |

`normal_attitude`는 문서 목록에 있지만 이번 Python 리터럴 대조로는 확인하지 못했습니다.
사용자 실물 확인 전 새 시나리오에 추가하지 않습니다. 다른 허용 동작 이름은 제조사 예제에서 확인했습니다.
예제에 프로젝트 제한 밖 move 값도 있지만 안전 제한은 넓히지 않습니다.

## 통신·추가 센서 예외

| 항목 | 확인한 사실 | 남은 확인 |
| --- | --- | --- |
| Wi-Fi | 제조사 예제 STA_IF와 UDP socket 사용; 순정 문자열 PM_NONE 존재 | 실제 절전 해제·공유기 지연 |
| 라이다 | UART1, rx32/tx33, 115200, rxbuf4096 설정; 순정 이미지에 UART·rxbuf 존재 | 숫자 인자는 문자열만으로 입증 불가; J5 회로 근거와 사용자 루프백 필요 |
| 스레드 | 전역 조립 → 함수 → startMain, 루프 양보 | 공식 호출 블로킹·스케줄링 |
| 업로드 | 여러 파일 import의 편집기 전송·검색 경로 보장 근거 불충분 | 한 파일 묶음 제공; 장치 메모리 여유는 REPL 확인 |

이 방식을 쓰는 이유는 두 로봇이 공식 Python 제어를 유지하면서 Pi에서 판단해야 하기 때문입니다.
카메라 안 인식 대신 맞춤 영상 펌웨어를 쓰므로 I2C의 결과 없음은 정상적인 연결 확인이며,
사람이 없다는 증거로 사용하지 않습니다. 예외·종료는 동작 그룹 중단과 이동 정지를 함께 시도합니다.
