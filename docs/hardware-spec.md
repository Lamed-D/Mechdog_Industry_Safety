# 동일 구성 로봇 A/B 하드웨어 명세

제품 제시값과 우리 장치의 실측값을 구분합니다. A/B는 고정 ID이며 주·보조 역할은 [통신 배정](robot-redundancy.md)합니다.
각 로봇은 4개 다리·앞 ESP32-S3 비전 모듈·등 RPLIDAR A1M8-R6을 갖추며 팔·집게·부가 서보는 없습니다.

## 본체·전원

| 항목 | 확인한 값 | 우리 장치에서 남은 확인 |
| --- | --- | --- |
| 서 있는 크기 | 214×126×138mm | 라이다·카메라·배선 포함 외형 |
| 제품 무게 | 약 560g | 최종 장착 상태 A/B 각각 무게 |
| 다리 | 8자유도, 고속 서보 8개와 링크 구조 | 하중 추가 후 자세·직진·회전 보정 |
| 배터리 | 7.4V, 1500mAh, 5C | 장치 라벨·상태·실효 운용 시간 |
| 제품의 운용 시간 표기 | 최대 60분 | 조명·영상·무선·라이다·보행 포함 조건에서는 미측정 |
| 메인 칩·실행 | 클래식 ESP32, 순정 MicroPython v1.21.0 | 각 보드 버전·실제 펌웨어 응답 |
| 충전기 | 제조사 제공 8.4V 2A | 실제 동봉 충전기 라벨·커넥터 일치 |

제품 제시값 근거: [공식 MechDog 제품](https://www.hiwonder.com/products/mechdog).
최대 사용 시간은 보증된 우리 운용 시간이 아닙니다.
충전은 전원을 끄고 동봉 충전기를 사용하며, 표시가 충전 완료로 바뀌면 분리합니다.
배터리 연결 방향과 덮개 고정은 제조사 절차를 따릅니다. 에이전트는 연결·충전·전원 조작을 하지 않습니다.
[공식 준비·충전 안내](https://docs.hiwonder.com/projects/MechDog/en/latest/docs/1.Getting_Ready.html).

## 다리 서보

제조사 제품 표는 HPS-0618SG를 명시합니다. 제조사 사양서에서도 전압·크기 항목을 확인했습니다.
실제 장착 라벨과 다르면 아래 값을 다른 모델에 적용하지 않습니다.

| 항목 | 제품 제시값 |
| --- | --- |
| 전압 | 6~8.4V |
| 스톨 토크 | 8.4V에서 6kgf·cm |
| 무부하 속도 | 8.4V에서 60°당 0.06초 이하 |
| 크기·무게 | 32×12×26mm, 14.5g |
| 정지 전류·스톨 전류 | 25mA 이하 / 2.5A 이하 |
| 펄스·회전 범위 | 500~2500µs / 0~180° |

근거: [공식 서보 사양](https://www.hiwonder.com/products/hps-0618sg).
이는 부품 명세이며 Python 동작 인자나 우리 로봇의 허용 자세 범위가 아닙니다.
다리 관절을 직접 PWM으로 구동하지 않고 공식 move·pose·action API만 사용합니다.
부가 서보 9/10과 set_servo는 사용하지 않습니다. 스톨 시험도 실행하지 않습니다.

## IMU·버스

순정 펌웨어 문자열에는 MPU6050과 QMI8658 이름이 모두 있습니다. 이것만으로 실물 칩을 판별할 수 없습니다.
공식 MPU 클래스 이름이나 read_angle 성공도 물리 칩 종류를 증명하지 않습니다.
사용자가 보드 실크·칩 마킹·해당 회로도 버전을 대조하고 공식 읽기 결과를 함께 기록합니다.
공식 장치를 raw I2C로 스캔·읽기·쓰기하는 판별 스크립트는 제공하지 않습니다.
주소·코드 버스와 물리 포트 대응은 [인터페이스 표](vendor-interfaces.md)를 사용합니다.

## 추가 센서·카메라

- 라이다는 UART1, IO32=RX·IO33=TX, 115200bps 고정, TCP 20108 원시 중계입니다.
  별도 5V로 먼저 확인하고, 탑재 전원은 실측 후 MP1584 같은 5V 강압 구성을 검토합니다.
  J5-1의 5V 여유는 미확인입니다. [배선·전원 설계](lidar-integration.md).
- 카메라 칩은 ESP32-S3입니다. 센서 실제 모델·플래시 용량·PSRAM은 사용자 확인 전입니다.
  컴파일 설정은 DIO 80MHz·4MB·OPI PSRAM이며 실제 용량을 증명하지 않습니다.
- 공식 제품 표의 영상 해상도 320×240은 제시된 동작값입니다. 센서 최대 해상도로 해석하지 않습니다.
  맞춤 펌웨어는 [VGA/SVGA 프로필](vision-quality.md)을 제공하고 실제 JPEG 차원과 성능으로 확인합니다.
- 고정 Pi 5 16GB는 Ubuntu 24.04 arm64·ROS 2 Jazzy·Python 3.12를 기준으로 합니다.
  Pi는 한 대의 조정자이며 두 로봇의 동일 장비 구성과 별개입니다. 모델 성능은 아직 미측정입니다.
