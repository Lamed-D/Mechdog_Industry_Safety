# Pi 5 영상 모델 검증 계획

현재 연결은 최신 프레임 수신·시간 창·unknown 정지만 제공하며 낙상 모델은 설치하지 않았습니다.
모델 후보가 실행된다는 사실과 쓰러진 사람을 정확히 판단한다는 사실은 별도로 검증합니다.

## 첫 비교 후보

MediaPipe Pose Landmarker Lite와 Full을 같은 영상 조건에서 비교합니다.
공식 모델은 사람 검출과 33개 자세 지점을 출력하며 그 자체가 낙상 분류기는 아닙니다.
검출 입력은 224×224, 자세 입력은 256×256입니다. 카메라 원본 해상도와 모델 입력 크기를 혼동하지 않습니다.
우리 전방의 낮은 장착 위치에서는 가려진 몸·화면 밖 신체·흔들림 때문에 자세가 누락될 수 있습니다.
이 경우 관측 불가를 정상으로 해석하지 않고 unknown으로 처리합니다.
Lite는 지연, Full은 자세 품질을 비교할 후보이며 Pi 5 실측 우열은 아직 없습니다.
근거: [공식 작업·모델 설명](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker).

공식 Python 지원 범위에는 Linux aarch64와 Python 3.12가 포함됩니다.
2026-11-10 확인한 PyPI 1.2.2에는 aarch64 배포물이 있습니다. Ubuntu 24.04의 실제 설치·실행은 [확인 필요]입니다.
프로젝트 기본 의존성에 모델 패키지를 추가하지 않았습니다.
근거: [환경 안내](https://developers.google.com/edge/mediapipe/solutions/setup_python),
[배포 파일](https://pypi.org/project/mediapipe/).

코드와 해당 모델 카드의 라이선스는 Apache 2.0입니다. 실제 선택한 가중치·버전·카드·해시를 함께 기록해야 합니다.
모델 카드는 생명 안전이 걸린 판단을 의도한 용도로 제시하지 않습니다. 이 프로젝트에서도 관리자 확인을 위한 관측 보조로만 평가합니다.
근거: [코드 라이선스](https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE),
[공식 모델 카드](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20BlazePose%20GHUM%203D.pdf).

## 우리 장비에 맞추는 점

- A/B의 시간 창과 자세 추적 상태는 분리합니다. 영상이 두 개여도 동일 사람이라는 추정을 하지 않습니다.
- 수신과 추론을 분리하고 최신 한 장만 처리합니다. 두 스트림의 디코딩·추론 시간을 함께 측정합니다.
- 자세 visibility/presence를 낙상 확률로 쓰지 않습니다. 별도 판단 규칙과 현장 보정 없이 신뢰도 값을 만들어 내지 않습니다.
- 기존 시간 창의 임계 0.8·유지 2초·관측 간격 0.5초는 검증 전 가정입니다. 오탐·미탐 결과로 다시 결정합니다.
- 누운 대체물, 빈 공간, 앉음, 가림, 저조도, 로봇 흔들림을 구분해 평가합니다. 실제 사람 영상은 저장소에 넣지 않습니다.
- `tools/vision_performance.py`의 모델 콜백으로 디코딩·추론 p95와 결과 나이를 측정합니다.
  모델 없음·저해상도·오류·오래된 결과는 unknown을 유지합니다.

두 스트림 동시 CPU·메모리·온도·지연, 낙상 판단 정확성, 장착 시야는 모두 [확인 필요]입니다.
Pi 성능을 확인하기 전 Jetson 전환이나 모델 속도를 보장하지 않습니다.
실물 경로·자세·제동 검증 전 고정 위치 어댑터의 이동 차단도 유지합니다.
