# 임시 시험: 초음파 거리로 도착하는 순찰

> ⚠️ **`feat/patrol-sonar-arrival-test` 브랜치 전용 임시 시험 기능입니다. `main`에는 없습니다.**
> 실물 주행 검증 전이고, 안전장치 일부를 일부러 풀었습니다. 사람이 로봇 곁에서 **정지·비상 정지(Esc)**를 바로 누를 수 있을 때만 쓰세요.

## 기존 방식과 다른 점

실행 옵션 `--patrol-arrive-mm`을 붙일 때만 바뀝니다. 붙이지 않으면 README의 기존 자율주행 순찰과 똑같이 동작합니다.

| 항목 | 기존 (선 없음) | 임시 시험 | 왜 (실물 시험에서 겪은 문제) |
| --- | --- | --- | --- |
| 도착 판단 | 태그가 미리 기억한 크기만큼 크게 보이면 | 앞 **초음파 거리**가 지정값(예: 40 cm) 이하가 되면 | 태그마다 크기를 미리 저장해야 하고, 인쇄·화면 크기가 바뀌면 다시 저장해야 함 |
| 미리 할 일 | 태그마다 '여기서 멈춤' 크기 기억 | 없음 | 위와 같음 |
| 다가가기 | 보폭 15, 태그가 가운데가 아니면 제자리 회전 | 태그를 보면 **보폭 50으로 직진**하며 방향만 살짝 조정 | 짧은 걸음과 제자리 회전이 반복돼 거의 걷지 않음 |
| 번호 확인 | 멈추자마자 | **완전히 멈추고 0.8초 뒤** 찍힌 화면으로 | 걷는 중 흔들린 화면에서 번호 인식이 실패함 |
| 다음 태그 찾기 | 5초 안에 못 찾으면 중단 | **찾을 때까지 계속 제자리 회전** | 5초 제한에 걸려 다음 태그를 찾기 전에 멈춤 |
| 걷다가 태그를 잠깐 놓침 | 바로 중단 | 2초까지는 직진 유지 | 흔들려서 잠깐 놓친 것만으로 순찰이 끝남 |
| 초음파 값 없음, 앞 30 cm 이하 | 시작 불가·중단 | **막지 않음** (안전 규칙 완화) | 태그를 붙인 판 자체가 장애물로 잡히고, 초음파 값이 자주 끊김 |
| 걸을 때 배터리 순간 하락 | 바로 중단 | 3초 넘게 낮을 때만 중단 | 보폭 50으로 걸을 때 순간적으로 7.0 V 밑으로 떨어져 중단됨 |
| 중단 뒤 다시 시작 | 첫 지점부터 | **멈춘 태그부터 이어서**, ↻ 버튼은 처음부터 | 다시 시작하면 1번부터 가서 이미 지난 태그를 또 따라감 |
| 기록 | 없음 | 오른쪽 **도착 확인** 칸에 시작·발견·도착·중단(해결법 포함)과 그 순간 사진. 노트북 메모리에만 최대 30건, 서버를 끄면 사라짐 | 왜 멈췄는지 현장에서 알 수 없음 |

이 브랜치에서는 옵션과 상관없이 자율주행 탭 화면도 바뀌었습니다.

| 바꾼 것 | 왜 |
| --- | --- |
| 주행 방식·도는 방향을 버튼으로(기본 **선 없음**) | 드롭다운을 매번 열어야 해서 불편함 |
| 맨 위 안내 칸에 **방금 / 지금 / 다음** 동작 | 로봇이 갑자기 돌아서 당황스러움, 다음 동작을 미리 알아야 함 |
| 카메라 아래에 보이는 태그 번호·초음파 거리, 영상 위 태그 번호 크게 | 태그 번호가 작아서 안 보임 |
| 버튼 줄 **잠금 해제(완료) · ↻ · 순찰 시작 · 정지**, 시작 못 하는 이유 표시 | 잠금 해제하려고 조종 탭을 오가야 했고, 시작 버튼이 왜 꺼졌는지 알 수 없었음 |
| 잠금 해제 확인창을 탭 밖으로 옮김 | 자율주행 탭에서 확인창이 0×0으로 열려 잠금 해제가 안 되던 버그 |
| 이름 변경: 한 바퀴 시작 → 순찰 시작, 도착 기준 저장 → 지금 보이는 태그 크기를 '여기서 멈춤'으로 기억, 태그 N 인쇄 → 태그 N(+ 인쇄 방법 창) | 원래 이름이 무엇을 하는지 알기 어려움 |

## 실행 방법

1. GitHub Desktop에서 **Current branch → `feat/patrol-sonar-arrival-test`**로 바꾸고 Pull 합니다.
2. 카메라·본체를 노트북 핫스팟에 연결하고, 저장소 폴더에서 실행합니다. 로봇 ID, 카메라 IP, 도착 거리(mm, 300~1500)는 실제 값으로 바꿉니다.

   ```powershell
   python -m dashboard.server --robot B --hotspot --allow-real --cam http://<카메라IP>:81/stream --patrol-arrive-mm 400
   ```

3. `http://127.0.0.1:8090` → **자율주행** 탭에서 방문 순서(예: `1,0`)와 도는 방향을 고릅니다.
4. 로봇을 첫 태그에서 **도착 거리보다 멀리**(예: 1 m) 두고 **잠금 해제 → 순찰 시작**을 누릅니다. 이미 도착 거리 안이면 걷지 않고 바로 도착으로 처리합니다.
5. 멈춘 이유와 해결법은 **도착 확인** 칸에서 봅니다. 끝나면 실행 창에서 `Ctrl + C`로 서버를 끕니다.
