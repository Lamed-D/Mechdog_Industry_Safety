다음 태그를 찾을 때 도는 방향


선 없음 방식은 태그가 이만큼 크게 보이면 도착했다고 판단합니다. 로봇을 멈추고 싶은 자리에 직접 두고, 화면에 태그 하나만 보이게 한 뒤 누르세요. 방문 순서의 태그마다 한 번씩 필요합니다.

도착 확인 (임시 시험)

    태그 인쇄 방법

    1. 0번·1번 태그는 저장소의 ai/patrol-print/apriltag-stations-a4.pdf를 엽니다. 1쪽이 0번, 2쪽이 1번입니다.
    2. 흰 A4 용지에 세로 · 단면 · 실제 크기 100%로 출력합니다. 흑백이면 충분합니다. 인쇄 창에서 '용지에 맞춤'과 '축소'를 끕니다.
    3. 종이 아래 확인선을 자로 잽니다. 확인선 50 mm, 검은 정사각형 한 변 140 mm여야 합니다. 다르면 인쇄 배율을 확인합니다.
    4. 흰 여백을 자르지 말고 평평한 판이나 벽에 붙입니다. 테이프는 종이 가장자리에만 붙이고, 빛이 반사되는 비닐은 피합니다.
    5. 0·1번 외의 태그는 태그 N 링크의 그림을 출력하되, 검은 정사각형 한 변이 140 mm가 되게 크기를 맞춥니다.
    6. 태그 높이는 사람 눈높이가 아니라 서 있는 로봇의 카메라 높이에 맞춥니다.
